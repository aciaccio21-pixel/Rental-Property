# Rental Steward

A private rental-property dashboard for tracking income, expenses, tenants, rent, estimated monthly costs, short-term-rental occupancy, and monthly or quarterly tax reports.

## Deploy to Render

The repository includes a Render Blueprint that creates both the Next.js web app and its PostgreSQL database.

1. Open the Blueprint link from this repository's deployment handoff.
2. Connect this GitHub repository and approve the `render.yaml` Blueprint.
3. Enter values for `APP_USERNAME`, `APP_PASSWORD`, and `APP_DISPLAY_NAME` when Render prompts you.
4. Create the Blueprint resources and wait for the health check to pass.

`SESSION_SECRET` is generated by Render and `DATABASE_URL` is connected automatically. The database schema is applied by the pre-deploy command.

## Local development

Prerequisites: Node.js 22+, pnpm, and PostgreSQL.

```bash
cp .env.example .env.local
pnpm install
pnpm run db:migrate
pnpm dev
```

Open `http://localhost:3000` and sign in with the username and password from `.env.local`.
